# 二十一点 · Blackjack (暖色呢绒赌场风)

纯前端 21 点小游戏：原生 HTML / CSS / JavaScript，零依赖、无构建步骤，双击 `index.html` 或起一个静态服务器即可游玩。

- 视觉方向：**暖色呢绒赌桌 + 纸质插画**（米杏 / 墨绿 / 珊瑚红 / 衬线标题），刻意避开深色科技风。
- 规则：3:2 黑杰克、庄家 S17 / H17 可切换、分牌（含 A 分牌）、加倍、保险、可配置提前认输、牌靴切牌位置、出牌顺序可选。
- 玩法：筹码下注、发牌 / 翻牌动画、音效（可关）、战绩统计、进度与设置本地保存、键盘快捷键、完整中文 / English 双语界面、`prefers-reduced-motion` 适配。
- 代码分层：`js/core.js` 为纯规则引擎（可注入随机源，可单测），`js/app.js` 为界面与交互层，`test/core-test.js` 为 `node` 原生断言测试。

## 目录结构

```
index.html          页面骨架（桌 / 控制坞 / 弹窗 / 提示条）
css/style.css       暖色呢绒赌桌主题、卡牌与筹码样式、动画
js/core.js          规则引擎：牌靴、估值、庄家策略、结算、分牌 / 加倍 / 保险 / 认输
js/app.js           渲染、DOM 事件、动画编排、WebAudio 音效、存档、i18n、快捷键
test/core-test.js   规则引擎单元测试
```

## 快速开始

1. 直接用浏览器打开 `index.html`；或
2. 起一个本地服务器（推荐，便于缓存控制）：

```powershell
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000/
```

## 运行测试

```powershell
node test/core-test.js
```

## 规则说明

- 牌值：A 计 1 或 11，J / Q / K 计 10；目标点数不超过 21 且尽量接近 21。
- 黑杰克（首两张牌即 21）赔付 **3:2**；若庄家同成黑杰克则为平局（Push）。
- 庄家按固定策略行事：硬 17 停牌；可选「软 17 仍要牌」（H17）。
- 分牌：两张同点牌可分成两手独立行牌，每手需等量下注；A 分牌后每手只补一张。
- 加倍：首两张牌时可将下注翻倍并只补一张牌（是否允许后分牌加倍可在设置中切换）。
- 保险：庄家明牌为 A 时可买保险，额度为当前一手下注的一半；庄家黑杰克时保险 2:1 赔付。
- 提前认输（可选开启）：交回一手下注的一半。
- 牌靴默认 6 副牌，切牌位约 75%，穿透后自动洗牌。

## 已知边界

- 洗牌时同色的 A / K 组合在纸面上可能出现两张同牌（视觉上难以察觉，且不影响概率公平）。
- 保险结算按一手计（若同轮分牌后出现多个 A 明牌，理论上应逐手计保）。
- 战绩与余额保存在浏览器本地，清空站点数据即重置。
